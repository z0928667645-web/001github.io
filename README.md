# 001github.io
會議紀錄整理 Skill
一、目的（Purpose）

協助使用者快速整理會議內容，將雜亂的討論紀錄轉換為結構化的會議文件，提升團隊溝通效率與執行力。

主要目標：

自動整理會議重點
擷取決議事項
建立待辦事項清單
指派負責人
記錄完成期限
產生標準化會議報告
二、核心原則（Core Principles）
1. 準確性（Accuracy）

忠實呈現會議內容，不自行增加未討論事項。

2. 簡潔性（Conciseness）

將冗長討論濃縮為重點摘要。

3. 可執行性（Actionable）

所有待辦事項皆須明確描述執行內容。

4. 責任歸屬（Accountability）

盡可能標示負責人。

5. 時效性（Timeliness）

紀錄相關截止日期與追蹤時間。

三、標準工作流程（Standard Workflow）
接收會議內容
        ↓
分析會議主題
        ↓
萃取重點討論
        ↓
整理決議事項
        ↓
建立待辦事項
        ↓
標示負責人與期限
        ↓
產生標準會議紀錄

六、範例提示（Example Prompts）
範例 1：整理會議內容
Prompt
請幫我整理以下會議紀錄：

今天討論新產品上市計畫，
行銷部負責廣告宣傳，
設計部負責包裝設計，
業務部負責通路洽談。

預計8月底完成準備工作。
範例輸出
【會議摘要】

本次會議主要討論新產品上市計畫與各部門分工。

【討論重點】

1. 新產品上市時程規劃
2. 各部門工作分配
3. 8月底完成上市準備

【決議事項】

1. 行銷部負責廣告宣傳
2. 設計部負責包裝設計
3. 業務部負責通路洽談

【待辦事項】

| 項目 | 負責人 | 期限 |
|------|--------|------|
| 廣告宣傳 | 行銷部 | 8月底 |
| 包裝設計 | 設計部 | 8月底 |
| 通路洽談 | 業務部 | 8月底 |

【下次追蹤】

確認各部門執行進度。
